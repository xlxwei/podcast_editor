# podcast_editor

在自己的 Mac 上剪對談型 podcast 的工具。每人一軌分開錄音（2 到 4 人），轉錄成逐字稿後，在瀏覽器裡圈字決定刪哪裡、拉波形修接點，輸出剪好的對話。

設計成和 Claude Code 一起用：轉錄、分章節、建議刪減由 Claude 做，你在頁面上決定留或刪。

## 需要

- Apple Silicon 的 Mac
- Claude Code
- 每個人各自一軌的錄音檔，時間對齊、長度相同

## 開始

在這個資料夾打開 Claude Code，跟它說：

> 照 CLAUDE.md 幫我檢查環境，我要剪一集新的。

之後每一步它會帶你做。不知道怎麼操作就直接問它。

## 你會用到的兩個頁面

- **逐字稿頁**：整集的逐字稿，劃線的字是剪掉的。拖曳圈一段字可以刪掉，圈劃線的字可以改回留著，按「▶ 剪後」聽剪完的樣子。最上面顯示目前剪後的長度。
- **微調頁**：每一刀前後的波形。接點聽起來有殘字或被吃字時，在這裡拖紅線修。

## 還沒有的功能

- 片頭、片尾、配樂和正式的混音。輸出的是只有對話的試聽版。
- 在頁面上搬移段落的順序（要搬請跟 Claude 說）。
